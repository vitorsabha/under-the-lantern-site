Privacy policy

Last updated: 8 November 2026

"Under the Lantern" is a private, single-user application run by the owner of the YouTube channel Rain Under the Lantern. It is not offered to the public and has no users other than the channel owner.

What the application does

The application reads statistics about the owner's own YouTube channel through the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API: views, watch time, subscribers, traffic sources, thumbnail impressions, estimated revenue and the list of the channel's videos. It never uploads, edits or deletes anything on YouTube.

What data is stored and where

The statistics are stored in a database on the owner's own computer. The Google authorization token is stored in the macOS Keychain of that computer. Nothing is sent to any third party, and no data about viewers or other people is collected. YouTube only provides aggregated statistics.

Google user data

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions; revoking it deletes nothing on YouTube and stops the application from reading the channel.
